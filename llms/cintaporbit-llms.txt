# CINTAP ORBIT

> CINTAP Orbit is the AI-powered enterprise integration platform by CINTAP Inc. Unify apps, APIs, files, documents, and partners on one no-code integration platform.

CINTAP ORBIT (https://cintaporbit.com) is an enterprise iPaaS alternative for B2B integration, EDI, managed file transfer, intelligent document processing (IDP), API management, secure file collaboration, and AI agents that build and operate integrations. SOC 2 Type II certified. Every public page also has a Markdown mirror: append `.md` to the path (for example https://cintaporbit.com/apps/orbit-bpi.md).

## Products

- [Orbit BPI](https://cintaporbit.com/apps/orbit-bpi): Integration engine for process flows, connectors, EDI (X12, EDIFACT), APIs, and orchestration
- [MAPR AI](https://cintaporbit.com/apps/mapr-ai): Agentic mapping engine that drafts, dry-runs, and repairs complete mapping rule sets
- [SecureFlow MFT](https://cintaporbit.com/apps/secureflow-mft): Managed file transfer for AS2, SFTP, FTPS, and OFTP2 with encryption and audit trails
- [Orbit IDP](https://cintaporbit.com/apps/orbit-ocr): Intelligent document processing: PDF, invoice, and PO to structured JSON
- [Edge API Gateway](https://cintaporbit.com/apps/edge-api-gateway): Expose process flows as policy-controlled REST APIs with consumers, keys, and traffic logs
- [Orbit Vault](https://cintaporbit.com/apps/orbit-vault): Encrypted enterprise file storage, sharing, and collaboration
- [Trading Partner Management](https://cintaporbit.com/apps/trading-partner-management): One master record per customer, supplier, 3PL, and carrier, reused across every flow

## AI agents

- [AgentCosmos](https://cintaporbit.com/agentcosmos): The 14-agent family that runs inside Orbit, plus the Agent Gateway (MCP) for Claude, Cursor, and Copilot
- [Kepler](https://cintaporbit.com/apps/kepler): Orbit's super agent: answers from live tenant data, builds integrations, runs flows, confirms anything risky
- [Nova](https://cintaporbit.com/apps/nova): Kepler's build specialist: assembles whole integrations stage by stage on a live build rail
